# 📅 Attendance Management System

A simple **Python beginner project** that records a student's daily attendance and calculates their attendance percentage.

## 🚀 Features

* 👤 Enter student name
* 📅 Enter month
* 📆 Enter number of days
* ✅ Mark attendance as Present
* ❌ Mark attendance as Absent
* 🕐 Mark attendance as Late
* 🔒 Validates attendance input
* 📊 Calculates attendance percentage
* 🎓 Shows eligibility status
* 📋 Displays a complete attendance calendar

## 🛠️ Technologies Used

* Python
* Lists
* Loops
* Conditional Statements
* User Input
* String Methods
* Basic Calculations

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Command Prompt or VS Code.
4. Run:

```bash
python attendance.py
```

## 📌 Attendance Rules

* **P** = Present
* **A** = Absent
* **L** = Late
* Late attendance is counted as **50% attendance** in this project.
* **75% or above** → Eligible
* **Below 75%** → Short Attendance
